# 待开发玩法

- [X] 情侣转盘：组合执行者、动作、部位和时长，支持主题任务加码。
- [X] 情侣 Bingo：将互动任务排成 Bingo 盘，完成连线后获得奖励。
- [X] 默契问答：双方分别作答后同时揭晓，按答案一致度计分。
- [X] 记忆翻牌：翻开配对任务卡，完成匹配的互动任务。
- [X] 领地争夺：双方占领棋盘区域，完成任务获得行动点或攻击机会
- [X] 拍卖竞价：双方竞价争夺任务，出价越高奖励和任务强度越高
- [X] 节奏挑战：跟随节拍完成动作、接吻或互动，失误后执行惩罚
- [X] 盲盒抽奖：抽取奖励、任务、交换、免罚、双倍等特殊卡片
- [X] 合作生存：双方共享生命值，连续完成任务抵御事件，失败则扣除生命
- [X] 随机事件模式：每隔几回合触发“交换身份、任务升级、奖励翻倍”等事件
- [ ] 格子棋：根据每回合一方赢得的格子数量来决定抽怎样尺度的卡片，赢得的格子越多，能决定对方做越大尺度的卡片任务。
