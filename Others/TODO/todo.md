## 分类扩充与新玩法建议（待审核）

当前 4 个分类（经典 / 益智 / 互动 / 剧情），共 17 个玩法。建议新增「刺激」分类，候选玩法以「冒险 + 心跳 + 加码」为核心，尺度与刺激度明显高于现有玩法（均复用现有主题任务库，不新增题库）：

- [ ] 真心话大冒险·狂暴版：抽卡即答即做，含「禁区提问」「当众挑战」「连续三连」等高强度事件；失败方接受对方指定的大尺度惩罚（刺激分类）。
- [ ] 赌局轮盘：转盘压注，赌上「今晚的主权」——输家整晚听赢家差遣，任意尺度、不可拒绝（刺激分类）。
- [ ] 高潮边缘挑战：轮流把对方推到「临界点」，谁的定力先崩谁输，输家完成对方挑的高尺度任务（刺激分类）。
- [ ] 惩罚九宫格：每次失败在一个 3×3 惩罚格上落子，先连成线的一方主导整晚，惩罚逐格升级（刺激分类）。
- [ ] 秘密翻倍：翻开的每张任务卡都可选择「加码翻倍」——任务尺度随机翻倍，完成后奖励也翻倍，赌命式二选一（刺激分类）。
- [ ] 角色扮演剧本：随机抽取人设+场景+剧情走向，双方即兴演满一场，含权力反转与强制台词（剧情分类）。

> 说明：以上仅建议，待用户审核后再决定是否实现；分类名与玩法归属均可调整。所有高尺度内容延续项目一贯原则——明确同意、随时可跳过。
