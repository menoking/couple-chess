# 待开发玩法

 - [ ] 情侣转盘：组合执行者、动作、部位和时长，支持主题任务加码。
 - [ ] 默契问答：双方分别作答后同时揭晓，按答案一致度计分。
 - [ ] 情侣 Bingo：将互动任务排成 Bingo 盘，完成连线后获得奖励。
 - [ ] 记忆翻牌：翻开配对任务卡，完成匹配的互动任务。
 - [ ] 限时挑战：在倒计时内完成连续任务，按完成数量和难度计分。
 - [ ] 故事接龙：双方轮流抽取情节卡，共同推进随机情侣故事。
 - [ ] 领地争夺：双方占领棋盘区域，完成任务获得行动点或攻击机会
 - [ ] 拍卖竞价：双方竞价争夺任务，出价越高奖励和任务强度越高
 - [ ] 节奏挑战：跟随节拍完成动作、接吻或互动，失误后执行惩罚
 - [ ] 盲盒抽奖：抽取奖励、任务、交换、免罚、双倍等特殊卡片
 - [ ] 合作生存：双方共享生命值，连续完成任务抵御事件，失败则扣除生命
 - [ ] 随机事件模式：每隔几回合触发“交换身份、任务升级、奖励翻倍”等事件
