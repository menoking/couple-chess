## 验证方式

在项目根目录运行：

```powershell
npm run typecheck
npm run lint
npm run build
```

开发服务器：

```powershell
npm run dev -- --host 0.0.0.0
```

通常地址为 `http://localhost:5173/`。手机与开发电脑在同一局域网时，可使用 Vite 输出的 Network 地址访问。

## 注意事项

- `npm` 在当前 Windows 沙箱中会先输出 `Test-Path ... Access is denied`，但上述脚本仍可正常执行；应以脚本最终退出码为准。
- 当前工作区中的 `Others/MyCards/` 是未跟踪目录，包含待审核的新增题库资料。不要未经用户明确同意将其导入正式默认题库。
- 中文文件已有部分终端编码显示异常，编辑时避免对无关文件进行整文件重编码。
- 当前开发服务器可能由上一位 Agent 启动；修改源码后 Vite 会自动热更新，若进程已停止再重新运行启动命令。
